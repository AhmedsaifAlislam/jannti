# لقطات المتجر — جنتي

هذا المجلد يحمل لقطات صفحة المتجر الرسمية، وكل لقطة تُنتَج من كادر المشهد
الثابت لا من تحريك يدوي للكاميرا.

## الملفات

| الملف | المقاس | الاستخدام |
|---|---|---|
| `01-home-1080x1920.png` | 1080×1920 | Google Play — الهاتف |
| `01-home-1290x2796.png` | 1290×2796 | App Store — iPhone 6.7" |

اللقطتان من **كادر الافتتاح** نفسه: `_kHome*` في `lib/screens/jannati_3d_screen.dart`
— كاميرا `(150, 172, 180)` إلى هدف `(0, 2, 0)`، و`_resetCamera` يقرأ الثوابت
ذاتها. لذلك أي تغيير بيئي (B6) يعني إعادة التصدير لا إعادة التأطير.

## خطوات إعادة الإنتاج

### 1. ابنِ وقدّم نسخة الويب

```powershell
flutter build web
python -m http.server 8099 -d build/web
```

### 2. افتح **صفحة جديدة** واضبط المقاس قبل التحميل

هذه أهم خطوة. تغيير مقاييس الجهاز عبر CDP **بعد** أن يبني Flutter تخطيطه
يُبقيه على المقاس القديم، فيخرج المحتوى مقصوصًا من اليمين (جُرِّب وسقط).
لذلك: صفحة لم تُحمَّل فيها النسخة بعد، ثم:

```js
const viewport = { width: 540, height: 960 }; // أو { width: 645, height: 1398 }
await page.setViewportSize(viewport);
const cdp = await page.context().newCDPSession(page);
await cdp.send('Emulation.setDeviceMetricsOverride', {
  ...viewport, deviceScaleFactor: 2, mobile: false,
});
await page.goto('http://127.0.0.1:8099/');
```

| المقاس النهائي | Viewport (CSS) | DPR | مدخل المشهد |
|---|---|---|---|
| 1080×1920 | 540×960 | 2 | بطاقة **«جنتي 3D»** في صف الإجراءات السريعة (≈ `400, 252`) |
| 1290×2796 | 645×1398 | 2 | تبويب **«جنتي»** الثاني من اليمين في الشريط السفلي (≈ `403, 1355`) |

### 3. انتظر الرئيسية ثم افتح «جنتي»

انتظر ~6 ثوانٍ حتى تستقر الرئيسية، ثم افتح المشهد بالمدخل الموافق للمقاس
(الجدول أعلاه). شريط التبويبات RTL وترتيبه: الأذكار (يمينًا) · جنتي · السكينة ·
الإحصاءات (يسارًا)؛ عند 645×1398 يقع «جنتي» عند `x = 645 × 5/8 ≈ 403`.

> عند 540×960 استخدم بطاقة «جنتي 3D» لا الشريط السفلي: الشريط ملتصق بحافة
> الشاشة وهندسة نقره أقل ثباتًا، والبطاقة هي ما أنتج لقطة 1080 فعليًا.

### 4. انتظر استقرار المشهد ثم التقط

المشهد يدخل بلاطات الأرض والموديلات تدريجيًا. الانتظار المعتمد **21 ثانية**
(4 للتبويب + 17 لبقية الموديلات) قبل `page.screenshot`. اللقطة أثناء الدخول
تُظهر بلاطات ناقصة، وهي غير صالحة للمتجر.

### 5. حالة التطبيق المفروضة

- `flutter.has_seen_onboarding = "true"` — لا شاشة تعريف.
- `flutter.day_light_mode = "2"` — إضاءة الظهيرة، وهي المستخدمة في اللقطتين.
- الشريط السفلي ينسحب تلقائيًا بعد ٣ ثوانٍ داخل «جنتي»؛ الشريط الظاهر في
  أسفل الصورة هو **شريط الزرع** الخاص بالمشهد، لا شريط التنقل.

## ملاحظات

- اللقطتان تُظهران HUD المشهد وشريط الزرع عن قصد: هذه هي الشاشة كما يراها
  المستخدم، بلا عناصر مخفية.
- كادر الافتتاح يضع الجزيرة في النصف السفلي من الشاشة الطويلة، وهو سلوك
  أصلي في `_kHome*` وليس خطأ قصّ.
- بعد B3 (حاجب أول إقلاع) وB6 (أي تغيير بيئي) تُعاد اللقطتان بالخطوات نفسها
  وتُستبدل الملفات بأسمائها هذه.
