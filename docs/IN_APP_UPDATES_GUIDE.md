# دليل إرسال التحديثات للمستخدمين (خارج Google Play Console) 🚀✨

نظام التحديث التلقائي المدمج في **«جنّتي» (Jannati In-App Auto Updater)** يتيح لك إرسال أي تحديث جديد لجميع المستخدمين بضغطة زر وبدون الحاجة لامتلاك حساب Google Play Console.

---

## 🛠️ كيف يعمل النظام؟
1. عند فتح التطبيق (أو عند ضغط المستخدم على **«التحقق من التحديثات 🔄»** في مركز التنبيهات):
   - يقرأ التطبيق ملف `version.json` من الرابط السحابي المحدد في:
     `lib/services/app_update_service.dart` (المتغير `updateConfigUrl`).
2. إذا كان `version_code` في الملف السحابي **أكبر** من رقم النسخة المثبتة عند المستخدم (`currentVersionCode`):
   - تنبثق شاشة راقية بتصميم روحاني فاخر (زمرد وذهب).
   - تعرض للمستخدم عنوان التحديث ورقم الإصدار وقائمة الميزات الجديدة.
   - عند ضغط المستخدم على **«تحميل وتثبيت التحديث الآن ⚡»**:
     - يبدأ مدير تنزيلات أندرويد بتحميل ملف الـ APK فوراً وبشكل رسمي.
     - فور اكتمال التنزيل، يفتح الهاتف شاشة التثبيت ليتم تحديث التطبيق دون مساس بأي بيانات أو أذكار محفوظة!

---

## 📦 خطوات إطلاق تحديث جديد في 3 دقائق:

### الخطوة 1: رفع رقم الإصدار في التطبيق
في ملف `pubspec.yaml` وفي `lib/services/app_update_service.dart`:
```dart
static const int currentVersionCode = 2; // زوّد الرقم
static const String currentVersionName = '1.0.1';
```

### الخطوة 2: بناء ملف الـ APK
شغّل الأمر التالي في الطرفية:
```bash
flutter build apk --release
```
ستجد الملف الناتج في:
`build/app/outputs/flutter-apk/app-release.apk`

### الخطوة 3: رفع ملف الـ APK وتحديث `version.json`
1. ارفع ملف الـ APK إلى:
   - **GitHub Releases** (الخيار المجاني الأفضل والأسرع عالمياً بدون حدود للباندويث).
   - أو أي موقع استضافة مباشر (مثل Firebase Hosting / VPS / Dropbox مباشر).
2. حدّث محتوى ملف `version.json` كما يلي:
```json
{
  "version_name": "1.0.1",
  "version_code": 2,
  "min_supported_version_code": 1,
  "title": "تحديث جديد مبارك لـ جنّتي ✨",
  "release_notes": [
    "إضافة أصوات طبيعية نقية جديدة لخلوة الذكر",
    "تحسين أداء واستقرار مشهد الفردوس ثلاثي الأبعاد",
    "اعتماد أيقونة جنّتي الملكية الرسمية"
  ],
  "apk_url": "رابط_تحميل_الـ_APK_المباشر_هنا",
  "web_url": "رابط_صفحة_المشروع",
  "force_update": false
}
```

بمجرد حفظ الملف على الرابط، **أي مستخدم في العالم يفتح تطبيق جنّتي سيتلقى التحديث فوراً!** 🌟
